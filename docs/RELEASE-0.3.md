# Three Resonances — 0.3.0

The journey now continues beyond the Grove into two complete connected regions. Existing v2 saves remain usable. After the Bellkeeper, dash through Memory Threshold and continue east.

- **25 rooms / 3 regions / 3 major bosses.** Grove’s original nine rooms remain; Cathedral and Ashen Hollow each add eight.
- **Cathedral:** limited oxygen before the boss, a working three-position water valve, organ platform route, optional underwater archive, Mira’s three-part quest and the three-phase Drowned Cantor. Tide Breath grants unlimited underwater oxygen and upward/downward swimming.
- **Ashen Hollow:** animated lava hazards, a three-wheel furnace lock, a moving bridge, Wren’s three-part quest and the three-phase Ashbound Knight. Ember Guard opens the vault and makes hot floors safe, rewarding a return through earlier rooms.
- **Progression:** four health/energy collectibles, three real equippable relics, six quest fragments, NPC rewards, region-specific discovered maps and travel among activated shrines.
- **Art/audio:** two new original backgrounds, sixty usable atlas entries, four animated enemy families, two six-pose bosses, NPC portraits and four new music arrangements.
- Healing cannot restart repeatedly while its recovery animation is running. Damage-reduction equipment and assist difficulty now combine correctly.

Keyboard, touch and standard Gamepad API input remain available. Hold jump/up to swim upward after Tide Breath; down swims downward. Equip one relic in the inventory (I / pause → Eşyalar). All controls can be viewed from the title/pause menus.

Remaining four regions and nine bosses are planned, not shipped. There is no verified play-duration or physical-device 60 FPS claim. Generated sprites retain some clipping/proportion variation. No physical iPhone, Android or controller was available; mobile emulation and input fixtures supplement desktop Chromium.
